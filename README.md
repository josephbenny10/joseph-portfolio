# SEPH — Video Editor Portfolio

A personal video editing portfolio showcasing film edits and short-form cinematic reels.

## About

I'm Joseph Benny (SEPH), a video editor based in Kerala, India. I primarily create film edits and cinematic reels using DaVinci Resolve.

## Tech Stack

- React
- Vite
- Tailwind CSS
- JavaScript

## Features

- Selected video edits
- Featured showreel
- Responsive design
- Interactive project previews
- Contact and Instagram links

## Run Locally

```bash
git clone https://github.com/josephbenny10/joseph-portfolio.git
cd joseph-portfolio
npm install
npm run dev
```
